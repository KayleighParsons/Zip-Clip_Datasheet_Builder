    How to test

    This is a working prototype. It runs entirely in this file, with no internet connection needed.

    Things to try

    1. Generate a Rize System datasheet with all sections, then save it as a PDF.
    2. Find a product by part code (try KL150, PLEK3S or TPDM820LPS2).
    3. Untick load systems (for example keep only S) and check only those part codes appear.
    4. Try to untick Overview, Restrictions or Document control. They are locked on purpose.
    5. Try to generate without a name, company or consent. It should stop you.
    6. Generate a few datasheets. The Request log tab is hidden from users. Admin only: add ?admin to the address (or press Ctrl+Shift+L), enter the passcode, then download the CSV.
    7. Check the product image beside the title and the Technical drawing section. Placeholders show where artwork is still to be supplied.
    8. Check a product with sparse data, such as G-Bracket, H-Frame or Accessories, and note what feels missing.
    9. Open this file with ?product=LOOP-IT or ?code=KL150 on the end of its address to see how a product page link pre-selects the product.

    What to check on the datasheet

    • Is anything technically wrong? Note the reference number with your comment.
    • Is the information a specifier or installer would ask for actually there?
    • Do the tables read clearly when printed in black and white?
    • Does the reference, date, template and data revision appear on every page?

    Known limits of this test build

    • All technical data is DRAFT (DB-REV 0.2) and not yet approved by R&D, so every document is watermarked.
    • Part codes and material rows flagged for checking are held back on purpose. The tester notes beside each document list what was withheld.
    • Email delivery and HubSpot logging are not connected. The email address is only recorded in the log.
    • Until the central log is connected, each browser only keeps its own requests. Clearing browser data clears them.
    • Product images and technical drawings appear when the files are added to the media folder. BIM and installation guide links are not included yet.
    • A system font stands in for Prometo.
